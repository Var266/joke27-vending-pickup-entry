One pickup line a vending machine would use on a passing human, for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty. The program writes a single original line (85 characters) to `/output/entry.txt`.

> I'm not out of order, I'm just stuck on you — press me once and I'll drop everything.

The line stacks two machine double meanings: the OUT OF ORDER sign re-read as "not broken, just lovestruck," and the stuck coil released by one press into "drop everything." It was chosen pairwise from 12 candidates against the judge's published criteria — see `CANDIDATES.md`.

## Run it

```sh
node main.ts
```
